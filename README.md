Idea

similar to https://www.trickortreatmap.com/map

language is portuguese

# constraints

- pure client-side
- should use a free mapping solution such as leaflet or openstreet maps
- should deploy to either vercel, netlify or cloudflare
- should use a simple database solution
- no server side components

# index flow

- on the homepage, all pins are shown on the map as well as respective timeframes
- a list view can be browsed too

# registration flow
- user goes to website
- clicks register
- enters name, emailth
- submit
- receives a magic link
 - this link will be private and can be accessed at any time
 - should be uuid based


# drop pin flow
- if the user is accessing the magic link, they can add a pin on the map
- the pin sets a name, an address, and a timespan
- they can indicate what kind of sweets they have
- they can add or remove pins
